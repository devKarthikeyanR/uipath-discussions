RPA Architecture & Infrastructure Sizing

UiPath Unattended License: 1 Concurrent Token across Multiple Target Nodes

✓ 100% Resource Efficiency
Metaphor 1 · Licensing
Floating Concurrent Token
Like a Floating RDS / Citrix CAL. We provision 5 VM endpoints, but only own 1 active session token. Any VM can run the bot, but only one session is active at a time.
Metaphor 2 · Compute
Single Core FIFO Queue
Like a single CPU core with a task scheduler. Jobs execute sequentially in a queue. We don't buy a second CPU core until process wait-time exceeds acceptable SLA.
Metaphor 3 · Management
Orchestrator = License Broker
Orchestrator acts as the Load Balancer / License Server. It checks out the single runtime token to VM A, finishes the job, returns the token, and checks it out to VM B.
Infrastructure Parameter
Sequential Execution (1 Token)
Parallel Execution (N Tokens)
Orchestrator Dispatching Job scheduling mechanism
✓FIFO Job Queue: Orchestrator holds subsequent triggers in queue until the active VM checks back the runtime token.
–Concurrent Spawns: Tasks launch immediately on multiple VMs at the exact same timestamp.
UiPath Software Licensing Annual recurring software OPEX
✓1x Unattended Runtime (~$8k/yr): License is dynamic/floating across the entire Machine Template pool.
–Nx Unattended Runtimes ($8k/yr per VM): Multiplies licensing cost linearly for low-duty-cycle processes.
VM Topology & Isolation Security boundary between teams
✓Full Isolation Preserved: We maintain separate VMs (Finance VM, HR VM) with segregated creds and networks.
–Same multi-VM setup, but requires redundant idle license overhead on each machine.

Summary for IT Sponsors
We are provisioning isolated VM targets for departmental security, while utilizing a single floating execution token to maximize license utilization. Orchestrator queues the traffic automatically. If process volume spikes and queue latency breaches business SLAs in the future, we can scale to concurrent execution instantly by purchasing an additional token without changing any infrastructure.
Machine Template Architecture: UiPath Orchestrator dynamically associates 1 Unattended Runtime across an entire Machine Template containing multiple VM endpoints.
