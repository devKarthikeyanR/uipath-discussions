The "Company Car" Analogy How resources are shared across VMs
✓Like having one car but 5 authorized drivers (Virtual Machines). Only one driver can take the car at a time.
–Buying a separate car for every driver so everyone can drive simultaneously.
Execution Behavior What happens when tasks overlap?
✓Queued. If Finance is running on VM A, an HR task triggered on VM B will wait in a queue until the license is released.
–Simultaneous. Both the Finance task and the HR task execute at the exact same millisecond.
UiPath Licensing Cost Annual recurring software fees
✓Maximized ROI. Pay for just one license (~$8,000/yr) that "floats" dynamically to whichever VM needs to do work.
–Expensive. Cost multiplies linearly (e.g., 3 tasks running at once = ~$24,000/yr in licenses).
Machine Setup & Isolation Where the bots actually live
✓We still deploy multiple Virtual Machines for different departments to maintain strict security, data isolation, and distinct logins.
–Also requires multiple VMs, but each has a dedicated license firmly locked to it.
The Complete Financial Picture
Treat an Unattended Bot like a digital employee. Its cost comes in three parts: 1. The Brain (UiPath Unattended License + Orchestrator to manage the waiting queue), 2. The Desk (Cloud/Server infrastructure costs for hosting the Virtual Machines), and 3. The Tools (App licenses for SAP, Excel, etc.). By pooling our workloads into a sequence, we only pay for one "Brain" while maintaining dedicated "Desks" for security.
Scalability note: This setup is highly flexible. If automation adoption grows and task queues become too long, we can simply add a second Unattended license later—no architectural rework required.
